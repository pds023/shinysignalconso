# Fonds de carte locaux

Les GeoJSON sont embarqués pour éviter toute requête externe lors de la consultation.

- `fr-regions.geo.json` : https://code.highcharts.com/mapdata/countries/fr/fr-all.geo.json
- `fr-departments.geo.json` : https://code.highcharts.com/mapdata/countries/fr/fr-all-all.geo.json

Téléchargés le 29 septembre 2026. Source : Highcharts Map Collection, données Natural Earth ; les mentions originales sont conservées dans les fichiers. Les cartes incluent les territoires ultramarins fournis par cette collection. Les jointures utilisent les codes INSEE et ISO 3166-2, et non les anciens identifiants Highcharts du classeur historique.

Conditions d’utilisation : https://www.highcharts.com/docs/maps/map-collection
